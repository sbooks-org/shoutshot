Accounts

By default Shoutshot uploads exactly like the websites do, with no key needed. To have uploads land in an account (e.g. a throwaway one), just log in to imgbb.com / imgur.com in this browser. If you're logged out, uploads are anonymous guest uploads. Press Test to see which one you'll get.
Log in to imgbb.com
Get one at api.imgbb.com → Get API key. API uploads go to the account that owns the key.
Log in to imgur.com
Register at api.imgur.com/oauth2/addclient (choose OAuth 2 authorization without a callback URL) and paste the Client ID.
The test uploads a tiny 8×8 image and deletes it again right away (ImgBB: auto-deletes after 5 minutes).

{url} = direct image link, {viewer} = the image's page on Imgur/ImgBB.
Downloads/
Copies go into this folder inside your browser's Downloads folder.
Getting a Save As dialog for every upload? That's your browser's own "ask where to save" setting, and extensions can't override it. To stop the dialog, turn that setting off:
  • Brave or Chrome: Settings → Downloads → turn off Ask where to save each file before downloading.
  • Edge: Settings → Downloads → turn off the option that asks where to save each file.
This changes it for every download in the browser, not just Shoutshot's. Or untick "Save a copy" to stop saving copies.
